## Failure found: Spectrum Bars

Spectrum Bars runs at about 27 FPS on this display. Nearly every frame is
slow. It fails the p05 rule, as it did on 08/10 (p50 25.1). The PHI-174
density cap does not fix it on this display. This belongs to PHI-174.

- It also fails with the fixture WAV, so the controller audio is not the cause.
- With the flash guard skipped (`NO_GUARD=1`), it runs at 30.4 FPS, 223 slow
  per 1000. The guard adds about 6 ms per frame here, but it is not the main
  cost.
- It makes about 3,200 garbage collections in 15 s, against 14 for rings.
- Suspect, not proven: 264 rounded `rect()` calls per frame (88 bars x 3 glow
  layers) in p5 v1.9.0 WEBGL mode, which builds new geometry for each call.
